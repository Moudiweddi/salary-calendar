SALARY CALENDAR: INSTALL AS AN APP (free, GitHub Pages)

1. Go to github.com, sign up (free), and click New repository.
   Name it salary-calendar, set it to Public, and create it.
2. Click "uploading an existing file", drag in ALL files from this
   salary-app folder (index.html, manifest.webmanifest, sw.js, icon-192.png,
   icon-512.png, apple-touch-icon.png), then click Commit changes.
3. Go to Settings > Pages. Under Source choose "Deploy from a branch",
   branch main, folder / (root), then Save.
4. After about a minute the site is live at:
   https://YOUR-USERNAME.github.io/salary-calendar/
5. Open that link on your phone:
   - iPhone (Safari): Share > Add to Home Screen
   - Android (Chrome): menu (⋮) > Install app / Add to Home screen
   The app opens full screen with its own icon.

To update later: upload the new index.html to the repository (Add file > Upload files, replace the old one).
Your data is stored on each phone separately. Export to Excel regularly for a backup.
